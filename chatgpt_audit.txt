# VORNEXE — DEEP AUDIT\
\
## Overall target\
\
I'd build Vornexe toward this:\
\
\u003e **Premium streetwear brand + editorial experience + high-converting ecommerce**\
\
Not:\
\
\u003e “Cool animated ecommerce website.”\
\
That distinction should drive basically every decision.\
\
---\
\
# 🔴 P0 — Fix these before launch\
\
These are things that can directly hurt sales or make the site feel unfinished.\
\
## 1. Mobile UX\
\
**Priority: CRITICAL**\
\
I would treat mobile as the primary version.\
\
Your likely acquisition funnel is:\
\
**Instagram → Vornexe → product → cart → checkout**\
\
That means your customer probably isn't sitting at a 27-inch monitor.\
\
I'd test the site at:\
\
- 320px\
- 375px\
- 390px\
- 414px\
- 768px\
\
And specifically inspect:\
\
### Header\
Does the logo remain readable?\
\
### Navigation\
Can someone reach products in one tap?\
\
### Hero\
Does it communicate the brand without consuming the entire screen?\
\
### Product cards\
Can users understand what they're looking at?\
\
### Product page\
Can they select size easily?\
\
### Add to cart\
Is the CTA immediately obvious?\
\
### Checkout\
Is there friction?\
\
If any of those are awkward on mobile, fix them before adding more visual effects.\
\
---\
\
# 2. Product page\
\
This is **more important than the homepage**.\
\
A visitor might love your homepage and still not buy.\
\
The product page has one job:\
\
\u003e eliminate reasons not to purchase.\
\
I'd structure it around:\
\
**Product imagery**\
\
↓\
\
**Product name**\
\
**Price**\
\
**Availability**\
\
**Size selection**\
\
**Add to Cart**\
\
↓\
\
**Description**\
\
↓\
\
**Fit**\
\
↓\
\
**Material**\
\
↓\
\
**Shipping**\
\
↓\
\
**Returns**\
\
↓\
\
**More imagery**\
\
You should make the product page feel editorial rather than like a generic Shopify product template.\
\
---\
\
# 3. Size selection\
\
For streetwear this deserves special attention.\
\
Don't simply have:\
\
`S M L XL`\
\
Give the customer enough confidence to choose.\
\
For example:\
\
**Model:** 6'0\" / 183 cm  \
**Wearing:** L\
\
Then:\
\
**Size Guide**\
\
| Size | Chest | Length |\
|---|---:|---:|\
| S | ... | ... |\
| M | ... | ... |\
| L | ... | ... |\
| XL | ... | ... |\
\
If the fit is oversized:\
\
\u003e **Oversized fit — we recommend your usual size.**\
\
or whatever is actually accurate.\
\
Sizing uncertainty kills conversions.\
\
---\
\
# 4. Trust layer\
\
This should be extremely visible.\
\
You are an emerging brand.\
\
A customer doesn't yet have years of reputation to rely on.\
\
Therefore the website has to answer:\
\
**Who are you?**\
\
**Where are you based?**\
\
**How do I contact you?**\
\
**How long does shipping take?**\
\
**Can I return it?**\
\
**What happens if my order arrives damaged?**\
\
**Can I track it?**\
\
Put this information somewhere easy to find.\
\
I'd make the footer substantially more useful than a typical aesthetic-fashion footer.\
\

# 6. Your hero needs to sell the brand AND the collection\
\
This is a common mistake.\
\
A visually impressive hero can still be commercially useless.\
\
Don't just show:\
\
\u003e VORNEXE\
\
Instead give the user a reason to continue.\
\
Something like:\
\
**DROP 001**\
\
**[SHOP NOW]**\
\
The exact copy should obviously match your actual collection.\
\
The important part is the hierarchy.\

# 7. Navigation\
\
I'd keep the main navigation brutally simple.\
\
Something along the lines of:\
\
**VORNEXE**\
\
SHOP  \
COLLECTION  \
LOOKBOOK  \
ABOUT\
\
Then:\
\
SEARCH  \
ACCOUNT  \
CART\
\
Don't create a huge menu simply because you can.\
\
Streetwear sites benefit from restraint.\
\

# 8. Search\
\
Once you have enough products, search becomes important.\
\
It should support:\
\
- product names\
- categories\
- collections\
- possibly tags\
\
And ideally show results immediately rather than sending users through a clunky search page.\
\

# 9. Cart\
\
The cart should be extremely fast.\
\
I'd prefer a **slide-out cart drawer** over forcing the customer onto another page every time.\
\
Something like:\
\
**YOUR CART**\
\
Product\
\
Size\
\
Quantity\
\
Price\
\
---\
\
**Subtotal**\
\
**CHECKOUT →**\
\
Then:\
\
**Continue Shopping**\
\
Minimal.\
\

\
**Image 1**\
\
hover/touch →\
\
**Image 2**\
\

\
**QUICK VIEW**\

But don't make customers wait for elaborate transitions just to inspect a product.\

# 🟡 P2 — Polish\
\
These aren't launch blockers, but they'll move Vornexe from good to premium.\
\
## 11. Typography system\
\
Typography needs to be extremely deliberate.\
\
I'd use:\
\
### Display font\
\
Something distinctive.\
\
### UI/body font\
\
Something extremely readable.\
\
Don't use five different fonts.\
\
I'd establish:\
\
**H1**\
\
**H2**\
\
**H3**\
\
**Body**\
\
**Caption**\
\
**Price**\
\
**Button**\
\
and stick to those rules.\
\
---\

# 12. Spacing system\
\
Premium websites generally benefit from consistent spacing.\
\
Don't randomly use:\
\
`23px`\
\
`47px`\
\
`71px`\
\
everywhere.\
\
Create a spacing system.\
\
For example:\
\
`8 / 16 / 24 / 32 / 48 / 64 / 96 / 128`\
\
Then build the site around it.\
\
The website will immediately feel more intentional.\
\
---\

# 13. Animation system\
\
This is where I want you to be disciplined.\
\
I'd create three categories.\
\
### Micro\
\
100–250ms\
\
Buttons  \
Hover  \
Icons\
\
### UI\
\
300–600ms\
\
Menus  \
Cards  \
Page transitions\
\
### Brand\
\
1–2 seconds\
\
Entrance  \
Hero  \
Campaign transitions\
\
Don't make every component animate.\
\
**Motion needs hierarchy.**\
\
---\

# 14. Cursor effects\
\
If you're using custom cursor effects:\
\
Be careful.\
\
They're cool on desktop.\
\
They're useless on mobile.\
\
And if the cursor is constantly changing shape, following elements, producing trails, etc., it can make the site feel more like an experiment than a fashion brand.\
\
I'd use one subtle signature interaction.\
\
---\
\
# 15. Background effects\
\
Same principle.\
\
One distinctive background system is better than:\
\
- particles\
- gradients\
- noise\
- blur\
- glow\
- WebGL\
- moving shapes\
- grain\
\
all at once.\
\
You want:\
\
\u003e **recognizable**\
\
not:\
\
\u003e **busy**\

# ⚡ PERFORMANCE AUDIT\
\
This is one of the things I'd take seriously with Vornexe.\
\
You have to assume your visitors are going to come from Instagram on mobile.\
\
Imagine someone clicking your Instagram link while using:\
\
**4G + Chrome/Safari + 20% battery + 30 other tabs**\
\
If your homepage takes 5–8 seconds to become usable, you've lost people.\
\
### Targets I'd aim for\
\
**LCP:** \u003c 2.5s  \
**INP:** \u003c 200ms  \
**CLS:** \u003c 0.1\
\
And I'd try to keep the initial page extremely lean.\
\
---\
\
# Video\
\
If you're using background video:\
\
Don't load a gigantic 4K file.\
\
Use:\
\
**WebM/MP4**\
\
with appropriate compression.\
\
And consider:\
\
```text\
Desktop → video\
Mobile → optimized poster/image or lightweight video\
```\
\
depending on the design.\
\
The animation doesn't need to be identical across devices.\
\
---\
\
# Images\
\
Use:\
\
**AVIF/WebP**\
\
where appropriate.\
\
Don't serve:\
\
\u003e 5000 × 7000 image\
\
to a:\
\
\u003e 390px mobile screen.\
\
Use responsive image sizing.\
